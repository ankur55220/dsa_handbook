# Week 2 Discoveries

## Discovery 1 - State Thinking

The state contains only the information that determines future decisions.

---

## Discovery 2 - State vs Value

State

↓

Future

Value

↓

Current path quality

Never confuse them.

---

## Discovery 3 - Dominance

If two executions reach the same state,

and one always produces an equal or better future,

the worse execution can be pruned.

---

## Discovery 4 - Information Flow

Ask:

What information must survive between recursive decisions?

---

## Discovery 5 - Future Equivalence

Two executions are equivalent if every future choice is identical.

That's what defines a state.
